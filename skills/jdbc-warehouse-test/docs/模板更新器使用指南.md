# 批量入仓测试文件模板更新器 - 使用指南

## 📋 概述

为了避免 `test_data` 目录中测试文件过多，采用 **固定模板 + 单一最新测试文件** 的方案：

- **模板文件**：`batch_success_batch_test_warehouse_20260228104525.xlsx`（只读，不修改）
- **最新测试文件**：`batch_test_latest.xlsx`（每次覆盖更新）

## 🎯 解决的问题

1. ✅ **避免文件爆炸**：不再每次测试都生成新文件
2. ✅ **快速测试**：一条命令更新模板，立即可用
3. ✅ **灵活配置**：支持不同数据库类型、抽数方式组合

## 🚀 快速开始

### 基本用法（默认：增量合并）

```bash
cd jdbc-warehouse-test/scripts
python template_updater.py <实例> <数据库> <表名>
```

**示例**：
```bash
python template_updater.py cjjcommon dataops_shitingjie test_new_table
```

### 指定数据库类型

```bash
python template_updater.py <实例> <数据库> <表名> --db-type <类型>
```

**示例**：
```bash
# TiDB
python template_updater.py tidb-ares ares test_tidb_table --db-type tidb

# ADB
python template_updater.py adb-realtime stjtestadb test_adb_table --db-type adb
```

### 指定抽数方式和处理方式

```bash
python template_updater.py <实例> <数据库> <表名> \
  --extract-method <抽数方式> \
  --deal-method <处理方式>
```

## 📊 支持的组合模式

### 1. 增量合并（默认，推荐）

```bash
python template_updater.py cjjcommon dataops_shitingjie test_table \
  --extract-method ins \
  --deal-method merge
```

**适用场景**：
- 数据每天增量更新
- 需要保留历史数据并更新新数据
- 最常用的入仓模式

---

### 2. 全量覆盖

```bash
python template_updater.py cjjcommon dataops_shitingjie test_table \
  --extract-method all \
  --deal-method all
```

**适用场景**：
- 每次全量刷新数据
- 不需要保留历史数据
- 数据量较小的表

---

### 3. 增量分区

```bash
python template_updater.py cjjcommon dataops_shitingjie test_table \
  --extract-method ins \
  --deal-method ins
```

**适用场景**：
- 按日期分区存储
- 每天新增一个分区
- 适合大数据量场景

## 📝 参数说明

### 必需参数

| 参数 | 说明 | 示例 |
|------|------|------|
| instance | 实例名 | cjjcommon / tidb-ares / adb-realtime |
| database | 数据库名 | dataops_shitingjie / ares / stjtestadb |
| table | 表名 | test_new_table |

### 可选参数

| 参数 | 默认值 | 可选值 | 说明 |
|------|--------|--------|------|
| --db-type | mysql | mysql / tidb / adb | 数据库类型 |
| --extract-method | ins | all / ins | 抽数方式（all=全量，ins=增量） |
| --deal-method | merge | all / ins / merge | 处理方式（all=覆盖，ins=分区，merge=合并） |

---

## ⚠️ 注意事项

### 1. 合法组合

只支持以下3种组合：

| 抽数方式 | 处理方式 | 说明 |
|----------|----------|------|
| all | all | 全量覆盖 |
| ins | merge | 增量合并（默认，推荐） |
| ins | ins | 增量分区 |

**非法组合会报错**：
```bash
❌ 错误：抽数方式和处理方式组合不合法
```

---

### 2. 表名规范

- 只能包含小写字母、数字、下划线
- 不能以数字开头
- 建议以 `test_` 开头

---

### 3. 文件路径

脚本使用固定路径：
- 模板文件路径已内置
- 输出文件路径已内置

如需修改，编辑脚本开头的常量：
```python
TEMPLATE_FILE = "..."
OUTPUT_FILE = "..."
```
