# 模板更新器 - 快速参考卡

## 📍 脚本位置
```
jdbc-warehouse-test/scripts/template_updater.py
```

## 🚀 常用命令

### 1. MySQL 增量合并（默认，推荐）
```bash
python template_updater.py cjjcommon dataops_shitingjie test_table_name
```

### 2. MySQL 全量覆盖
```bash
python template_updater.py cjjcommon dataops_shitingjie test_table_name \
  --extract-method all --deal-method all
```

### 3. MySQL 增量分区
```bash
python template_updater.py cjjcommon dataops_shitingjie test_table_name \
  --extract-method ins --deal-method ins
```

### 4. TiDB 增量合并
```bash
python template_updater.py tidb-ares ares test_tidb_table --db-type tidb
```

### 5. ADB 增量合并
```bash
python template_updater.py adb-realtime stjtestadb test_adb_table --db-type adb
```

## 📂 文件说明

| 文件 | 说明 | 是否修改 |
|------|------|----------|
| `batch_success_batch_test_warehouse_20260228104525.xlsx` | 原始模板 | ❌ 只读 |
| `batch_test_latest.xlsx` | 最新测试文件 | ✅ 每次覆盖 |

## 🎯 支持的组合

| 抽数方式 | 处理方式 | 说明 | 命令参数 |
|----------|----------|------|----------|
| ins | merge | 增量合并（默认） | 默认，无需指定 |
| all | all | 全量覆盖 | `--extract-method all --deal-method all` |
| ins | ins | 增量分区 | `--extract-method ins --deal-method ins` |

## 📋 参数说明

```bash
python template_updater.py <实例> <数据库> <表名> [选项]
```

### 必需参数
- `实例`: cjjcommon / tidb-ares / adb-realtime
- `数据库`: dataops_shitingjie / ares / stjtestadb
- `表名`: test_table_name

### 可选参数
- `--db-type`: mysql (默认) / tidb / adb
- `--extract-method`: ins (默认) / all
- `--deal-method`: merge (默认) / all / ins

## ⚡ 快捷流程

```bash
# 进入脚本目录
cd jdbc-warehouse-test/scripts

# 1. 更新模板
python template_updater.py cjjcommon dataops_shitingjie test_new_table

# 2. 上传测试
python batch_upload_validate.py \
  "test_excel/batch_test_latest.xlsx"

# 3. 查询结果
python batch_query_result.py <taskId>

# 4. 提交任务
python batch_submit_task.py <taskId>
```
