# 批量工作流 - 快速参考

## 📍 脚本位置
```
jdbc-warehouse-test/scripts/batch_workflow.py
```

## 🎯 功能说明

**一键式完整工作流**，自动化执行：
1. ✅ 创建 N 个测试表（调用 test-table skill）
2. ✅ 完善 N 个表的元数据（调用 metadata-complete skill）
3. ✅ 生成批量上传文件（N 行数据）

## 🚀 常用命令

### 1. 默认模式（1 个表）
```bash
cd jdbc-warehouse-test/scripts
python batch_workflow.py cjjcommon dataops_shitingjie
```

### 2. 批量模式（3 个表，推荐）
```bash
python batch_workflow.py cjjcommon dataops_shitingjie --count 3
```

### 3. TiDB 环境
```bash
python batch_workflow.py tidb-ares ares --count 2 --db-type tidb
```

### 4. 自定义表名前缀
```bash
python batch_workflow.py cjjcommon dataops_shitingjie --count 3 --prefix my_test
```

### 5. 全量覆盖模式
```bash
python batch_workflow.py cjjcommon dataops_shitingjie --count 2 \
  --extract-method all --deal-method all
```

## 📋 参数说明

### 必需参数
- `instance`: 实例名（cjjcommon / tidb-ares / adb-realtime）
- `database`: 数据库名（dataops_shitingjie / ares / stjtestadb）

### 可选参数
| 参数                 | 默认值        | 说明                                     |
|--------------------|------------|----------------------------------------|
| `--count`          | 1          | 表数量（1-3）                               |
| `--prefix`         | batch_test | 表名前缀                                   |
| `--db-type`        | mysql      | 数据库类型（mysql/tidb/adb）                  |
| `--extract-method` | ins        | 抽数方式（ins=增量，all=全量）                    |
| `--deal-method`    | merge      | 处理方式（merge=合并，all=覆盖，ins=分区）           |
| `--row-count`      | 10         | 每个表的数据行数                               |
| `--data-type`      | mixed      | 数据类型（mixed/string/number/date/boolean） |

## 🎲 表名生成规则

表名格式：`{prefix}_{timestamp}_{序号}`

示例：
- `batch_test_02281430_01`
- `batch_test_02281430_02`
- `batch_test_02281430_03`

其中：
- `prefix`：表名前缀（可自定义）
- `timestamp`：时间戳（月日时分，确保唯一性）
- `序号`：2 位数字序号（01, 02, 03）

## 📦 生成的文件

**输出位置**：
```
JBDC入仓/BIZ_REQ_33706_001_批量入仓_新增任务/test_data/batch_test_latest.xlsx
```

**文件内容**：
- N 行测试数据（N = 表数量）
- 每行 23 列（符合批量入仓接口规范）
- 每行对应一个测试表的完整配置

## ⚙️ 支持的组合模式

| 抽数方式 | 处理方式 | 说明 | 参数 |
|----------|----------|------|------|
| ins | merge | 增量合并（默认） | 默认 |
| all | all | 全量覆盖 | `--extract-method all --deal-method all` |
| ins | ins | 增量分区 | `--extract-method ins --deal-method ins` |

## 🔄 完整测试流程

```bash
# 1. 生成批量测试文件（3 个表）
python batch_workflow.py cjjcommon dataops_shitingjie --count 3

# 2. 上传测试
python batch_upload_validate.py \
  "test_excel/batch_test_latest.xlsx"

# 3. 查询结果
python batch_query_result.py <taskId>

# 4. 提交任务
python batch_submit_task.py <taskId>

# 5. 发送审批消息（使用 mq-sender skill）
```

## ⚠️ 注意事项

### 1. 表数量限制
- **默认**：1 个表
- **最大**：3 个表（自动限制）
- **原因**：方便排查问题

### 2. 表名唯一性
- 自动生成时间戳确保表名唯一
- 避免与现有表冲突

### 3. 执行确认
- 脚本会显示将要创建的表名列表
- 需要用户输入 `y` 确认后继续

### 4. 失败处理
- 如果某个表创建失败，会询问是否继续
- 只有成功创建并完善元数据的表会被写入测试文件

### 5. 环境映射
脚本会自动映射实例名到环境名：
- `cjjcommon` → `cjjcommon`
- `tidb-ares` → `tidb-ares`
- `adb-realtime` → `adb-realtime`
- `bigdata-biz` → `bigdata-biz-dataops`
