### 知识分类体系 (B/A/T)

| 一级分类要素     | 二级分类要素 | 编码     | 定义与范畴 |
|:-----------|:-------|:-------|:-----------|
| **B-业务知识** | 业务流程类  | **BF** | 业务逻辑时序、流程图、活动图定义 |
|            | 业务规则类  | **BR** | 具体的计算逻辑、判定准则、业务约束 |
| **A-系统知识** | 系统数据类  | **AD** | 数据库表结构、字段定义、索引设计 |
|            | 系统接口类  | **AI** | API 定义（URL/入参/出参）、协议说明 |
|            | 系统消息类  | **AM** | MQ 消息体、生产/消费逻辑定义 |
|            | 系统任务类  | **AJ** | 定时任务 (Job)、后台批处理逻辑 |
|            | 系统缓存类  | **AC** | Redis 键值设计、过期策略、数据结构 |
|            | 系统配置类  | **AF** | 环境变量、功能开关、业务参数 |
|            | 系统工具类  | **AT** | 系统级 SDK、公共 Utility 组件 |
| **T-测试知识** | 测试操作类  | **TO** | 测试执行步骤、接口调用、数据库操作 |
|            | 测试断言类  | **TA** | 预期结果校验、数据库/接口断言 |
|            | 测试函数类  | **TF** | 测试用例中的动态数据函数 |
|            | 测试变量类  | **TV** | 全局变量、测试环境变量池 |
