# run_test.py 使用指南

## 📋 概述

`run_test.py` 是AI测试框架的测试执行入口，支持**单个测试用例执行**和**批量测试用例执行**两种模式。

---

## 🚀 快速开始

### 1. 单个测试用例执行

```bash
python run_test.py <测试用例文件路径>
```

**示例**:
```bash
# 执行正常流程测试用例
python run_test.py cases/TC_TKF001_001_离线剧本批量生成_正常流程.yaml

# 执行断点续传测试用例
python run_test.py cases/TC_TKF001_002_离线剧本批量生成_断点续传.yaml
```

**输出**:
- 控制台输出：测试执行过程、断言结果、执行时间
- HTML报告：生成在 `reports/` 目录下

---

### 2. 批量测试用例执行

```bash
python run_test.py <测试用例目录>
```

**示例**:
```bash
# 批量执行test_cases目录下所有.yaml文件
python run_test.py cases
```

**输出**:
- 控制台输出：每个用例的执行过程和汇总统计
- 任务目录：`reports/task_时间戳/`
  - `index.html` - 汇总报告（包含所有用例的统计和链接）
  - `TC_XXX_时间戳.html` - 每个用例的详细报告

---

## 📊 批量执行特性

### 任务目录结构

批量执行时，会自动创建一个任务目录：

```
reports/
└── task_20260210_173934/          # 任务目录（时间戳）
    ├── index.html                  # 汇总报告
    ├── TC_TKF001_001_20260210_173953.html
    ├── TC_TKF001_002_20260210_174004.html
    ├── TC_TKF001_003_20260210_174030.html
    ├── TC_TKF001_004_20260210_174037.html
    └── TC_TKF001_005_20260210_174041.html
```

### 汇总报告 (index.html)

汇总报告包含以下内容：

#### 1. **统计卡片**
- 总用例数
- 通过数量
- 失败数量
- 通过率
- 总耗时

#### 2. **测试用例列表**
每个测试用例显示：
- 状态标识（✅ PASS / ❌ FAIL）
- 用例ID和名称
- 执行时间
- 断言统计
- 详细报告链接

#### 3. **样式特点**
- 现代化渐变背景
- 响应式布局
- 卡片式设计
- 悬停动画效果
- 清晰的视觉层次

## 🎯 使用场景

### 场景1: 开发调试
**需求**: 快速验证单个测试用例

**命令**:
```bash
python run_test.py cases/TC_TKF001_001_离线剧本批量生成_正常流程.yaml
```

**优点**:
- 快速反馈
- 详细的控制台输出
- 单个HTML报告

---

### 场景2: 回归测试
**需求**: 执行所有测试用例，验证功能完整性

**命令**:
```bash
python run_test.py cases
```

**优点**:
- 一次执行所有用例
- 生成汇总报告
- 清晰的通过率统计
- 失败用例列表

---

### 场景3: 持续集成 (CI/CD)
**需求**: 在CI流水线中自动执行测试

**命令**:
```bash
# 在CI脚本中
python run_test.py cases

# 检查退出码
if [ $? -eq 0 ]; then
    echo "所有测试通过"
else
    echo "测试失败"
fi
```

**优点**:
- 自动化执行
- 生成可归档的报告
- 支持退出码检查

## 🔧 高级用法

### 查看帮助信息

```bash
python run_test.py --help
```

### 路径说明

- **相对路径**: 相对于 `run_test.py` 所在目录
- **绝对路径**: 也支持绝对路径（不推荐）

### 文件过滤

批量执行时，只会执行 `.yaml` 扩展名的文件，其他文件会被自动忽略。

---

## ⚠️ 注意事项

1. **测试用例格式**: 确保测试用例文件是有效的YAML格式
2. **原语注册**: 确保所有使用的原语都已注册
3. **数据库连接**: 确保数据库连接配置正确
4. **报告目录**: 报告目录会自动创建，无需手动创建
5. **并发执行**: 当前版本不支持并发执行，用例按顺序执行

## 📝 最佳实践

### 1. 测试用例命名规范
```
TC_<业务流程ID>_<序号>_<场景描述>.yaml

示例:
TC_TKF001_001_离线剧本批量生成_正常流程.yaml
TC_TKF001_002_离线剧本批量生成_断点续传.yaml
```

```
test_cases/
├── TKF001/                    # 按业务流程分组
│   ├── TC_TKF001_001_正常流程.yaml
│   ├── TC_TKF001_002_断点续传.yaml
│   └── TC_TKF001_003_失败重试.yaml
└── TKF002/
    └── ...
```

### 3. 报告管理
- 定期清理旧报告
- 在CI中归档重要报告
- 使用任务目录时间戳追踪执行历史
